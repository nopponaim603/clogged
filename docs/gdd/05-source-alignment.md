## 1. ขอบเขตและกติกาอ่านเอกสาร

Google Doc นี้ใช้ชื่อเวอร์ชัน **A 0.2** และอธิบายการส่งหน่วยสำรวจ งานในฐาน ระบบวัน AP ความหิว D100 และเงื่อนไขชนะ

GDD ใน repo เป็นเอกสาร **Unity V2** ซึ่งยึดพฤติกรรมของระบบใน `Unity-Projects/Assets/V2/` เป็นหลัก เพราะมีการพัฒนาต่อจาก A 0.2 แล้ว รายการในไฟล์นี้จึงแยกเป็น:

- **ตรงกัน** — มีใน A 0.2 และ V2 เหมือนกัน
- **V2 ขยายจาก A 0.2** — ไม่มีข้อความขัดแย้งชัดเจน แต่เป็นระบบที่เพิ่มภายหลัง
- **ขัดแย้ง / ต้องตัดสินใจ** — A 0.2 กับ V2 กำหนดคนละกฎ

จนกว่าจะมีการตัดสินใจใหม่ ให้ถือ [Core Mechanics](01-mechanics.md) เป็นกติกาปัจจุบันของเกม และใช้ตารางความขัดแย้งด้านล่างเป็นรายการให้เจ้าของเกมตัดสิน

## 3. ข้อมูลที่ V2 เพิ่มจาก A 0.2

รายการนี้ไม่ได้ขัดกับข้อความที่พบใน Google Doc แต่ควรรับเป็นส่วนหนึ่งของ A 0.2 รุ่นถัดไป:

| ระบบ V2 | พฤติกรรมปัจจุบัน | คู่มือ |
|---|---|---|
| Readiness | ยูนิตส่งสำรวจได้ 1 ครั้งต่อวัน และใช้ Readiness 1 หน่วย | [Core Mechanics §2.2b](01-mechanics.md#22b-readiness-ตั๋วเข้าถ้ำ--ไอคอนเป็นรูปดาบ) |
| Risk / หมอกแดง | Risk เริ่ม 80 และหักโอกาสตามระดับถ้ำ; การเคลียร์ถ้ำลด Risk | [Core Mechanics §4.3](01-mechanics.md#risk-หมอกแดง) |
| Buff Potion | ใช้ Materials สร้างโบนัส SV ถาวรให้ทั้งทีม | [Core Mechanics §5](01-mechanics.md#5-base-work--งานในฐาน) |
| Blessed | Ann รักษาแล้วให้ +10 SV ในทริปถัดไป | [Core Mechanics §4.3](01-mechanics.md#ตารางยูนิต) |

### 4.1 ความคลุมเครือภายใน Google Doc เอง

- ต้นทุนโบนัสส่งคู่ปรากฏทั้ง **+15** และ **+25**
- Hard Success ปรากฏทั้ง “โอกาสปลดล็อก / ดรอป” และ “ได้ชิ้นเมื่อ Hard Success”
- ข้อความเรื่อง Talent Dan ระบุเพิ่มโอกาสดรอป KEY/BOX แต่ก็ไม่มีสูตรหรืออัตราดรอป

ประเด็นเหล่านี้ควรแก้ในแหล่งต้นทางด้วย เพื่อไม่ให้เอกสารใน repo ถูกตีความต่างกันในรอบถัดไป

## 5. รายการให้เจ้าของเกมตัดสิน

- [ ] ยืนยันลำดับ Core Item: **Normal ปลดล็อกแล้ว Hard ได้ของ** หรือ **KEY + BOX อิสระกัน**
- [ ] ยืนยันโอกาส Core Item: **การันตีจาก Hard Success** หรือมีเปอร์เซ็นต์ดรอป
- [ ] ยืนยัน Hard Success threshold: **`SV / 2`** หรือ **`SV / 3`**
- [ ] ยืนยัน Fumble: **Hard → Missing 1 คน** หรือ **ทุกคนที่ไปร่วมทริป Hurt**
- [ ] ยืนยันโบนัสส่งคู่: **+15** หรือ **+25**
- [ ] ยืนยันการสะสม Trait: **ครั้งเดียวต่อขั้ว** หรือ **รวมตามจำนวน Trait**
- [ ] ยืนยันคำเรียกสถานะถาวร: **Death / Missing / Lost Signal**
- [ ] ยืนยัน Talent Dan: เพิ่มโอกาส Core Item หรือคูณ loot ปกติอย่างเดียว
